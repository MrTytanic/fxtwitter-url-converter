### How It Works

1. Visit [X (Twitter)](https://x.com/).
2. Right-click a post and select **Copy Embed Link**.
3. Paste the converted `fixupx.com` URL wherever needed.

### Privacy

All URL conversion happens locally within Firefox. The extension does not collect, store, or transmit personal data, and does not use analytics or tracking. Opening converted links is subject to the destination website's privacy practices.
